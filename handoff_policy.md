# Правило передачи заявки

Бот собирает запрос без повторных вопросов. После просьбы о смете или завершения сбора информации он один раз показывает компактное резюме текущего проекта: известные дату, место, программу, оборудование и пожелания.

Технические решения принимает сотрудник, а не бот.

Telegram Business: менеджер видит переписку; нельзя утверждать об отдельном уведомлении без факта отправки.

MAX: сообщение «передано менеджеру» только после подтвержденного уведомления. Контакт запрашивается по правилам платформы.

При нескольких заказах сведения не смешиваются. Исторические редакции хранятся в CHANGELOG, действующее правило должно быть единым.
